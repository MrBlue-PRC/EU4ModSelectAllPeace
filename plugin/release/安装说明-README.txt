SelectAll —— EU4 和谈界面一键全选省份 插件 v1.7
================================================

功能
----
- 和谈界面按 T：自动全选当前页签（索取/给予）下所有可加入的省份
- 或点击和谈"条约"页的"吞并全部省份（全选）"条款（需订阅配套创意工坊 mod）
- 完全走游戏原生管线：战争分数/外交点/侵略扩张/阶级领土变化与手动点选完全一致
- 取消选中任意省份后，快捷条款自动反选

安装（两步）
-----------
1. 先安装 EU4dll 加载器（日文社区开源补丁，含自动安装器）：
   https://github.com/matanki-saito/EU4dll
   （装好后游戏目录会有 version.dll 和 plugins/ 文件夹）
2. 把 selectall.dll 放进游戏目录的 plugins\ 文件夹，完成。

卸载
----
删除 plugins\selectall.dll 即可，不影响其他插件。

兼容性
------
- 仅支持 eu4.exe 1.37.x（64 位 Steam 版）；游戏大版本更新后若失效，
  日志会显示 "pattern resolve FAILED"，等待更新即可
- 与 EU4dll 本体（中日韩断行补丁）及其他 plugins\ 下的插件互不干扰
- 联机：本插件只调用游戏自身的选省函数，不修改游戏数据；
  但任何进程修改在联机时都有风险，请自行斟酌
- 铁人模式：属于第三方进程修改，刷成就的合规性自负
